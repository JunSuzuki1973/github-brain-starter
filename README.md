# github-brain-starter

**手元の知見を GitHub の非公開リポジトリにまとめて、Claude Code のクラウドのスレッドやスマホから使うためのテンプレートです。**
作者はこの仕組みを「GitHub Brain」と呼んでいます（GitHub の公式機能ではありません）。

## なぜ必要か
Claude Code のクラウドのスレッド（claude.ai/code のセッションやプロジェクト）には、**手元のPCにしかないものは届きません。**

| クラウドに届く | 届かない |
|---|---|
| リポジトリに入っている `CLAUDE.md`、`.claude/skills/`、agents、commands | 手元のPCだけに入れたスキル・プラグイン・MCP サーバー |
| claude.ai アカウントのコネクタ | `~/.claude` の個人設定とメモリ |

そこで、「AIに毎回説明している前提」をリポジトリにまとめておきます。
プロジェクトに追加すれば、以後に始まるスレッドはすべて、作業の前にこの中身を読み込みます。

```
手元のメモ（正本） ──写す──▶ 非公開リポジトリ（GitHub Brain） ──読む──▶ クラウドのスレッド・スマホ
                    ◀──────────── プルリクエストで提案 ─────────────┘
```

## 使い方（3ステップ）
1. **このテンプレートから自分のリポジトリを作る**
   右上の **Use this template → Create a new repository** を押し、公開範囲を **Private** にします。
   （フォークだと非公開にできないので、テンプレートから作ってください。）
2. **Claude GitHub App をそのリポジトリにインストールする**
   https://github.com/apps/claude から、作ったリポジトリへのアクセスを許可します。非公開リポジトリでも使えます。
3. **Claude Code のプロジェクトにリポジトリを追加する**
   プロジェクトの設定（歯車）→ 環境 で、リポジトリを追加します。追加した後に始めたスレッドから反映されます。

あとはスマホの Claude アプリからでも、「X の投稿案を3本作って」のように頼むだけです。

## 中身
| 場所 | 役割 |
|---|---|
| `CLAUDE.md` | スレッドが最初に読む、短い目次と約束 |
| `brain/profile.md` | あなたは誰で、何を目指しているか |
| `brain/style.md` | 文章の口調と、言ってはいけないこと |
| `brain/projects.md` | 今の仕事と状況 |
| `brain/lessons.md` | 過去の失敗と教訓（ここが育つほど賢くなる） |
| `brain/sources.md` | 調べ物の情報源とルール |
| `.claude/skills/research-with-sources/` | 出典つきで調べるスキル（数字の捏造を防ぐ） |
| `.claude/skills/draft-post/` | あなたの口調で下書きを作るスキル |
| `inbox/` | クラウドで分かったことを、プルリクエストで提案する箱 |

`brain/` の中身は**架空の人物「さき」のサンプル**です。自分の内容に書き換えてください。

## 運用のコツ
1. **正本は手元に置く**：リポジトリは「外でも使う、確定した方針・手順・型」だけの写しにします。作業ログは入れません。
2. **秘密情報は入れない**：APIキー・トークン・パスワード・取引先やお客さんの個人情報は、非公開リポジトリでも入れません。
3. **CLAUDE.md は短く**：スレッドは始まるたびに CLAUDE.md を読み込むので、長いほど使用量が増えます。詳しい内容は `brain/` に分けて、必要なときだけ読ませます。
4. **手元専用のものは書かない**：自分のPCのフォルダの場所や、PCにしかないツールの使い方は、クラウドでは使えません。
5. **書き戻しはプルリクエストで**：クラウドで分かったことは `inbox/` に提案させ、取り込むかどうかは自分で決めます。
