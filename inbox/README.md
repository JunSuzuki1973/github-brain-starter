# inbox：クラウドで分かったことの提案箱

クラウドのスレッドは `brain/` を直接書き換えず、ここに提案を置きます。
持ち主が中身を確認して、残す価値があるものだけを `brain/` に移します。

## 書き方
- 1件1ファイル。ファイル名は `YYYY-MM-DD_短い題名.md`。
- 中身は次の3つだけ。

```markdown
# 題名
- 分かったこと：
- 出典URL（あれば）：
- どのファイルに足すとよいか：brain/lessons.md など
```

## 流れ
1. スレッドが `inbox/` にファイルを追加し、プルリクエストを作る。
2. 持ち主がプルリクエストを読む。
3. 残すなら、内容を `brain/` の該当ファイルに移して、inbox のファイルは消す。
